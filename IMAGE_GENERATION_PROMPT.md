## 🎨 Style Keywords to Add

Add these to any prompt for better results:

**For Midjourney:**
```
--style raw --stylize 200 --ar 1:1
```

**For Leonardo AI:**
```
Style: Dark Cinematic, Photography
Elements: Neon Glow, Glass
```

**For Stable Diffusion:**
```
Negative prompt: blurry, low quality, text errors, watermark, 
extra colors, busy background, cartoon, anime
Steps: 30, CFG: 7, Size: 512x512
```
